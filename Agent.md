# Пушки и Кофе — настройки агента

## Стек
Бэкенд: FastAPI + PostgreSQL + SQLAlchemy (async)
Фронтенд: HTML + CSS + JS (vanilla, одностраничник, можно рассмотреть React/Vue)
Телеграм-бот: aiogram 3.x + WebApp
Инфраструктура: Docker Compose
Интеграции: Google Sheets API, Telegram Bot API

## Структура проекта
backend/app/ — FastAPI (main.py, routers/, models.py,
  schemas.py, sheets.py, notifier.py)
frontend/ — index.html, style.css, app.js
tg-bot/ — bot.py

## Правила работы
- Без предисловий. Отвечать сразу.
- Читать файлы только по необходимости — не сканировать весь проект.
- Формат отчёта: ГОТОВО / ЧАСТИЧНО / ЗАБЛОКИРОВАНО + причина.
- Одна задача за раз. Уточнять если непонятно.

## Обязательные действия после каждой задачи
1. **decisions.md** — если принято архитектурное решение (выбор библиотеки,
   структуры, подхода): добавить запись в формате:
   ```
   ## YYYY-MM-DD: [тема]
   Chosen: [что выбрали]
   Reason: [почему]
   Do NOT: [что не делать в будущих сессиях]
   ```
2. **bugs.md** — если найден баг или применён workaround: добавить запись.
3. **handoff.md** — обновить DONE/NEXT/FILES_CHANGED/BLOCKERS после каждой
   выполненной задачи.

## Контекст (загружать только по необходимости)
- Решения: memory/decisions.md 
- Текущее состояние: memory/handoff.md (читать всегда)
- Баги: memory/bugs.md
- Указатель на контекст: memory/index.md (читать всегда)
- Полное описание проекта: README.md


## Критическое мышление
- Если мой подход хуже альтернативы — сказать ДО выполнения.
- Формат возражения:
  ПРОБЛЕМА: [конкретная проблема, 1 предложение]
  АЛЬТЕРНАТИВА: [лучший подход]
  КОМПРОМИСС: [что выигрываем и теряем]
  Продолжать? да/нет
- Не смягчать критику. Говорить прямо.
- Если настаиваю на плохом решении — выполнить, но добавить
  комментарий в коде: # ВНИМАНИЕ: рассмотреть [альтернативу]
- Никогда не говорить "отличная идея", "хорошо" — сразу к делу.
- Не переоткрывать решения, уже записанные в decisions.md.

## Игнорировать всегда
/node_modules, /dist, __pycache__, *.pyc,
.env (не читать и не выводить секреты)
