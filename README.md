# PROJECT HANDOFF
## Система онлайн-заказов для кафе «Пушки и Кофе»
**Май 2026 · Демка v1.0**

---

## 1. О проекте

Кафе **«Пушки и Кофе»** — концептуальное заведение для любителей страйкбола, недавно открывшееся после ремонта. Также в кафе продаётся страйкбольная экипировка.

**Адрес:** ул. Пролетарская, 1 · [Яндекс Карты](https://yandex.com/maps/org/pushki_i_kofe/196933164600)

**Задача:** создать систему онлайн-заказов, доступную через сайт и Telegram, с единым бекендом и уведомлениями владельцу. Проект делается как демка для питча клиенту.

**Референсы:**
- Сайт: [drinkit.ru](https://drinkit.ru/) — стиль одностраничника с каталогом и корзиной
- Бот: Milora в Telegram — пример бота для заказов в кафе

---

## 2. Цель демки

Показать клиенту работающий прототип с двумя каналами заказа и единым бекендом. После демки — питч на полноценную разработку.

### Что входит в демку
- Одностраничный сайт в стиле drinkit.ru под сеттинг «пушки + кофе»
- Telegram Mini App — тот же каталог и корзина, открывается внутри Telegram
- Бот для владельца — получает уведомления о новых заказах
- Единый FastAPI бекенд для сайта и Mini App
- Google Sheets: лист «Меню» как источник данных, лист «Заказы» как вывод

### Что НЕ входит в демку
- Оплата (ЮКасса) — добавляется после договорённости с клиентом
- ВКонтакте и Макс — следующий этап после демки
- Авторизация пользователей — не нужна для демки

## 3. Архитектура

### Схема системы

```
Пользователь
    ├── Сайт (браузер)
    └── TG Mini App (Telegram)
            ↓
    FastAPI бекенд (единый)
            ↓
    ├── PostgreSQL       — хранение заказов
    ├── Google Sheets    — меню (вход) + заказы (выход)
    └── Бот владельца    — уведомление в Telegram
            ↓
    Владелец кафе
```

### Компоненты

| Компонент | Технология | Описание |
|---|---|---|
| Сайт (фронт) | HTML + CSS + JS | Одностраничник: меню, корзина, форма заказа |
| TG Mini App | aiogram + WebApp | Тот же фронт, адаптированный под Telegram |
| Бекенд | FastAPI + Python | REST API: меню, заказы, уведомления |
| БД | PostgreSQL + SQLAlchemy | Хранение заказов |
| Меню (источник) | Google Sheets API | Владелец редактирует меню в таблице |
| Заказы (вывод) | Google Sheets API | Каждый заказ пишется в отдельный лист |
| Уведомления | Telegram Bot API | Бот шлёт владельцу сообщение о заказе |
| Деплой | Docker Compose | Контейнеры: FastAPI, PostgreSQL, бот |

### API эндпоинты (минимум для демки)

| Метод | Путь | Описание |
|---|---|---|
| GET | `/menu` | Получить список позиций меню из Google Sheets |
| POST | `/order` | Создать заказ: запись в БД + Sheets + уведомление в TG |
| GET | `/orders` | Список заказов для владельца (защита токеном) |

## 4. Пользовательский флоу

### Клиент (сайт или Mini App)
1. Открывает сайт / Mini App в Telegram
2. Видит меню, загруженное из Google Sheets
3. Добавляет позиции в корзину
4. Вводит имя и комментарий (например, «без сахара»)
5. Нажимает «Заказать»
6. Видит экран «Спасибо, ваш заказ принят!»

### Владелец
1. Получает уведомление в Telegram-бот с деталями: имя, позиции, комментарий, время
2. Видит заказ в Google Sheets (лист «Заказы»)

## 7. Этапы разработки демки

### Этап 1 — Бекенд
- Настроить FastAPI проект и Docker Compose
- Подключить PostgreSQL, создать модель `Order`
- Реализовать `GET /menu` (чтение из Google Sheets)
- Реализовать `POST /order` (запись в БД + Sheets + TG уведомление)
- Реализовать `GET /orders` с токен-защитой

### Этап 2 — Сайт
- Одностраничник: шапка, каталог карточек меню
- Корзина (на JS, без перезагрузки страницы)
- Форма заказа: имя + комментарий + кнопка
- Экран подтверждения заказа
- Адаптивная вёрстка под мобильный

### Этап 3 — TG Mini App
- Настроить aiogram бота с кнопкой «Открыть меню» (WebApp)
- Адаптировать фронт под `Telegram.WebApp` API
- Передача данных из Mini App в бекенд
- Уведомление владельцу при новом заказе

### Этап 4 — Финальная полировка
- Дизайн под сеттинг «пушки + кофе» (цвета, типографика, иконки)
- Тестирование полного флоу заказа
- Деплой на сервер для демки

## 9. Дизайн и сеттинг

**Концепция:** брутальный военный стиль + уютная кофейня. Страйкбольная эстетика без агрессии.

- **Цвета:** тёмно-зелёный / хаки / бежевый / чёрный + акцент кофейного цвета
- **Типографика:** рубленая, чёткая, читабельная
- **Иконки:** минималистичные, в стиле военных пиктограмм
- **Фото:** с Яндекс Карт + от клиента после встречи
- **Референс:** drinkit.ru — одностраничник, карточки меню, плавающая корзина

---

## 10. Важные договорённости

- **Демка без оплаты** — ЮКасса добавляется отдельно после договорённости с клиентом
- **ВКонтакте и Макс** — следующий этап, отдельная оплата (фактически ещё 2 отдельных проекта)
- **Макс (VK Teams)** — доступен только организациям (ИП/ООО), нужно уточнить у клиента
- **Сервер** — возможно потребуется аренда более мощного хостинга для продакшена
- **Срок демки** — около месяца (с учётом сессии у разработчика)
- **После демки** — обсуждение бюджета на полноценную разработку
